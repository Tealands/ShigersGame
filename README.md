# Shiger's Game

Shiger's Game is a React single-page app built with Vite. The home page, Sudoku completion page, and all five games are React components. Game rules and CPU move selection live in separate modules under `src/games`.

Site: https://tealands.github.io/ShigersGame/

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The Vite base path is configured for the repository's GitHub Pages URL (`/ShigersGame/`).
