# Shiger's Game

ブラウザーですぐに遊べる、React製のゲーム集です。ホーム画面から6種類のゲームを選べます。ゲームの状態は原則としてブラウザー内で管理し、対局用サーバーやアカウント登録は必要ありません。

公開サイト: https://tealands.github.io/ShigersGame/

## ゲーム

- **数独** — 9×9の盤面を数字で埋めるパズルです。入力した解答をチェックできます。
- **移碁** — 石を置いて相手の石を囲む対局ゲームです。移動モードでは自分の石を隣の空点へ動かせます。捕獲数の表示、パス、投了に対応し、盤面はブラウザーに自動保存されます。新しい対局を始めた後も、直前の盤面を復元できます。
- **盤面保存** — 数独、移碁、囲碁五目並べで進行中の盤面をブラウザーのローカルストレージに自動保存します。ゲームを切り替えても保存内容を復元でき、新しい対局開始時は直前の盤面を残せます。
- **予想五目** — 五目並べをCPUまたは二人で対局します。CPUの思考中に次の着手を予想し、的中・不的中に応じてポイントを獲得します。
- **囲碁五目並べ** — 五連を作ることと相手の石を囲んで取ることを組み合わせたゲームです。二人対戦とCPU対戦を選べます。
- **限定五目並べ** — 石数の上限に達した後は自分の石を移動して対局を続けます。二人対戦、CPU対戦、思考時間制限などを設定できます。
- **マインスイーパー** — 地雷を避けて安全なマスを開き、所持金を残してクリアを目指します。詳しいルールは「[マインスイーパー](#マインスイーパー)」を参照してください。

### 数独

9×9の盤面に1から9までの数字を入れるパズルです。Easy、Medium、Hardの問題を選べます。各行・各列・太線で区切られた3×3のブロックに、同じ数字を重複させず配置します。解答が完成したら「Check Solution」で正誤を確認できます。

### 移碁

黒と白が交互に石を置き、相手の石を囲んで盤上から取り除く対局ゲームです。通常モードでは空いている交点に石を置きます。移動モードでは、自分の石を隣接する空点へ動かせ、手番ごとに最大2回まで移動できます。相手の石が囲まれたグループは捕獲され、捕獲数に反映されます。パス、投了、一手戻すにも対応します。

### 予想五目

CPU対戦または二人対戦で五目並べを遊べます。盤面の縦・横・斜めに自分の石を5つ並べると勝利です。CPUの手番では思考中に次に置かれる位置を予想できます。予想が的中すると「+1 pt」、外れると「-1 pt」になります。勝利時には追加で「+100 pt」を獲得します。

### 囲碁五目並べ

囲碁の石取りと五目並べを組み合わせたゲームです。二人対戦、または後手のCPUとの対戦を選べます。19×19の盤面に石を置き、着手によって相手の石の呼吸点をなくすとグループを捕獲できます。呼吸点がない自殺手や、過去と同じ盤面に戻る千日手は禁止されています。石の5連を作ると勝利します。

### 限定五目並べ

各プレイヤーに置ける石の上限を設定できる五目並べです。二人対戦またはCPU対戦で遊べます。上限に達するまでは空き交点に石を置き、上限に達した後は自分の石を別の空き交点へ移動できます。縦・横・斜めに5つの石を並べると勝利です。石の上限や思考時間制限も設定でき、過去と同じ盤面に戻る手は禁じられています。

## 開発

Node.jsを用意し、リポジトリのルートで次のコマンドを実行します。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザーで開いてください。ソースを直接開いたり、Pythonなどの静的ファイルサーバーを使ったりするのではなく、Viteの開発サーバーを利用してください。

### 本番ビルド

```sh
npm run build
```

ビルド成果物は `dist/` に作られます。`npm run preview` で本番ビルドをローカル確認できます。

## GitHub Pagesへの公開

このリポジトリにはGitHub Actionsのデプロイワークフローがあります。GitHubのリポジトリ設定で **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。その後、`main` ブランチへpushするか、Actionsタブからデプロイワークフローを実行すると、ビルドと公開が行われます。

Viteのベースパスは `vite.config.js` で `/ShigersGame/` に設定されています。プロジェクトページのURLで動作するよう、画像・効果音などのアセットはビルド時に取り込まれます。

## マインスイーパー

マインスイーパーはブラウザーだけで動作します。ゲーム状態とクリア実績は利用中のブラウザー内で管理し、サーバーへの通信やアカウント登録はありません。

### 基本ルール

- 難易度は地雷 **100・200・300個** から選びます。開始時の所持金は地雷数 × `1,000$` です。
- マスをクリックして開きます。数字は周囲8マスにある地雷の数です。地雷以外の安全なマスをすべて開くとクリアです。
- 最初の通常クリックで選んだマスには地雷がありません。ただし、先に仲間への依頼や撤去依頼を使った場合はこの保護は適用されません。
- 地雷を踏むと治療費 `100,000$` が発生します。ゲームは続けられます。
- クリア時の残金が成績になり、儲け・自分で見つけた地雷数・被弾数が表示されます。

### 仲間と撤去依頼

- **仲間に任せる** — 1回 `500$`。ランダムな未開封マスを調査し、安全なら開き、地雷なら「×」で知らせます。
- **撤去依頼** — 1マス `100$`。モードをオンにしてマスを選ぶと、地雷を撤去します。安全なマスを選んだ場合は、そのマスを開きます。モードはオフにするまで継続します。
- どちらも所持金が足りている場合に利用できます。

### 旗・操作・実績

- 右クリックで旗を設置します。旗と異なる色を選んで右クリックすると色を変更し、同じ色で右クリックすると旗を外します。旗の色はボタン、または盤面上でマウスホイールを押し込んで切り替えます。
- 画面はマウスホイールでスクロールできます。
- 効果音は地雷を踏んだとき、マスを開いたとき、旗を置いたとき、仲間への依頼や撤去が行われたとき、クリア時などに再生されます。
- クリア実績はブラウザーのローカルストレージに保存され、ホーム画面に総クリア回数と直近5件の成績が表示されます。実績は利用中のブラウザーに保存されます。

### 盤面データとアセット

盤面データは `Assets/field/field.txt` にあります。`?` がプレイ可能なマスで、それ以外の文字は壁です。フィールドはViteのビルドに取り込まれます。効果音は `Assets/Sounds/` にあります。

## プロジェクト構成

- `Assets/src/App.jsx` — ホーム画面、ハッシュルート、ゲーム一覧
- `Assets/src/games/` — 各ゲームのReactコンポーネントとゲームロジック
- `Assets/src/components/` — 複数のゲームで使うコンポーネント
- `Assets/src/styles.css` — 共通および各ゲームのスタイル
- `Assets/field/`、`Assets/Sounds/` — マインスイーパーの盤面データと効果音
- `.github/workflows/static.yml` — GitHub Pagesへのビルド・デプロイ
